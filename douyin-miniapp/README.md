# AI店铺运营管家抖音小程序

这是一个可以放到抖音开发者工具里运行的小程序 MVP，定位是：

```text
上传/填写商品资料 -> 生成商品上架包 -> 生成客服 FAQ -> 生成7天托管方案 -> 留资成交
```

第一版不自动发布商品，只生成草稿、托管报价和执行计划。价格、库存、售后、发货承诺必须由商家人工确认后再发布。

## 怎么打开

1. 打开抖音开发者工具。
2. 选择导入项目。
3. 项目目录选择：

```text
C:\Users\Administrator\Documents\运营\douyin-miniapp
```

4. 确认 `project.config.json` 里的 `appid` 是你的抖音小程序 AppID。
5. 在抖音开放平台后台配置 request 合法域名：

```text
https://wjhai.cn
```

6. 点击编译预览。

## 当前能测试什么

- 首页选择商品样例：美妆精华、电商零食、手机壳。
- 填商品名、类目、平台、价格、SKU、卖点、目标客户、库存、发货、售后。
- 点击 `立即生成上架包和托管方案`。
- 结果页展示：
  - 商品标题草稿
  - 主图/详情图提示词
  - 详情页结构
  - SKU/价格/库存
  - 客服 FAQ
  - AI 店铺运营托管报价
  - 7 天执行计划
  - 发布队列和人工确认边界
  - 发布前风险检查
- 点击 `复制整套上架资料` 可以复制给运营、美工或平台后台使用。
- 点击 `复制托管报价方案` 可以直接发给客户成交。
- 点击 `请求真实主图` 会请求服务器图片接口；如果服务器图片模型没有配置，会保留提示词，不假装已经出图。
- 点击 `我要接入这个系统` 会进入留资页，提交商品托管需求到后台线索池。

## 线上接口

小程序默认请求：

```text
https://wjhai.cn/merchant-admin/api
```

新增接口：

```text
POST /ecommerce/listing-draft
POST /product-media/pack
```

已有图片接口：

```text
POST /images/generate
```

托管报价和 7 天执行计划由小程序根据商品资料本地生成，不依赖未上线的远程路由。商品媒体包接口失败时，小程序会用本地草稿兜底并明确显示没有真实媒体产物；线索提交失败会提示失败，不再假装已提交。

## 上架审核建议

建议类目选择接近：

- 企业服务
- 效率办公
- 营销服务
- 商家经营工具

审核说明可以写：

```text
本小程序为商家电商素材、商品上架草稿和运营托管方案生成工具。用户填写商品资料后，系统生成商品标题、主图提示词、详情页结构、SKU 草稿、客服 FAQ、7天执行计划和托管报价。小程序不自动发布商品，不自动修改价格和库存，不处理退款发货，不承诺收益，最终发布由商家人工确认。
```

## 还没有覆盖

- 还没有做真实商品图片上传到对象存储。
- 还没有接抖音小店官方商品发布 API。
- 还没有做订单、库存、售后数据读取。
- `请求真实主图` 依赖服务器图片模型配置，未配置时只返回提示词。
- 自动发布商品必须后置，先走草稿和人工确认。
