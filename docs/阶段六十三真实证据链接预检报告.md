# 阶段六十三：真实证据链接预检

## 目标

阶段六十二已经能生成客户追证草稿。阶段六十三继续减少“客户提交了但链接不可用或不安全”的返工：在证据导入前对客户提交的证据 URL 做安全结构检查和轻量可达性预检。

## 新增能力

- 后端新增 `POST /api/v1/ops/platform-acceptance-evidence-url-precheck`。
- 导入预览 `POST /api/v1/ops/platform-acceptance-evidence-import` 自动附带 URL 预检结果。
- Manifest 提交生成的导入预览也会包含 URL 预检结果。
- 前端新增 `URL precheck` 按钮，可单独检查一批证据链接。
- 前端导入结果每条 item 显示 URL 预检状态。

## 安全边界

- 预检不会登记通过证据。
- 只允许完整 `https://` 链接。
- 拦截 placeholder、localhost、内网/private IP、保留地址和 unsafe redirect。
- HTTP 可达性异常只作为 warning，避免误伤需要客户账号权限才能访问的证据链接。
- 真实导入仍需要运营人工审核，并使用 `CONFIRM_PLATFORM_EVIDENCE` 显式确认。
