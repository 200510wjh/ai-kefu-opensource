# 阶段十一 报表导出与自动化调度报告

生成时间：2026-07-16

## 一、阶段目标

本阶段目标是让经营报表可以导出、复制，并具备进入 Workflow 自动化的入口。

## 二、本阶段完成内容

### 1. 新增报表导出

修改文件：

- `backend/customer_service_saas.py`

新增模型：

- `ReportExportResponse`

新增能力：

- 将报表导出为 Markdown 文件。
- 文件写入 `/artifacts/reports/`。
- 返回 `artifact_url` 和报表全文。
- 导出写入用量记录和审计日志。

### 2. 新增日报 Workflow Runner

新增能力：

- `run_daily_report_workflow`

该能力会：

- 创建 `daily_business_report` Workflow run。
- 生成日报。
- 写入 Workflow 日志。
- 写入用量记录。

### 3. 新增 API

修改文件：

- `backend/api_v1.py`

新增接口：

- `POST /api/v1/reports/daily/run`
- `GET /api/v1/reports/{report_id}/export`

### 4. Workflow 定义补充

修改文件：

- `backend/platform/workflow.py`

新增默认 Workflow：

- `daily_business_report`

### 5. 前端经营分析接入

修改文件：

- `src/main.tsx`

报表卡片新增：

- 复制报表
- 导出 Markdown

## 三、安全边界

本阶段当时只导出 Markdown。

PDF/Word 导出已在阶段十四接入，当前系统支持 Markdown、PDF 和 Word DOCX 三种报表导出格式。

## 四、验证结果

已执行并通过：

- `python -m py_compile backend\main.py backend\api_v1.py backend\customer_service_saas.py backend\platform\workflow.py backend\platform\security.py`
- `POST /api/v1/reports/daily/run` TestClient 冒烟
- `GET /api/v1/reports/{report_id}/export` TestClient 冒烟
- 导出文件存在于 `/artifacts/reports/`
- `daily_business_report` Workflow 定义可见
- `npm run build`
- `npm run secret-scan`
