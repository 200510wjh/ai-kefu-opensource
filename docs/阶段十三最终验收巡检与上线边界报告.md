# 阶段十三：最终验收巡检与上线边界报告

生成时间：2026-07-16 20:10:00

## 本阶段目标

把“是否可以交付”从口头判断变成可运行的后端巡检结果，明确通过项、风险边界、阻断项和下一步动作。

## 已完成内容

- 新增最终验收巡检模型：
  - `AcceptanceAuditRequest`
  - `AcceptanceAuditItem`
  - `AcceptanceAudit`
- 新增巡检后端函数：`run_acceptance_audit`
- 新增 Markdown 巡检报告输出：`/artifacts/acceptance/{audit_id}.md`
- 新增 v1 API：
  - `POST /api/v1/acceptance/audit`
- 新增权限：
  - `acceptance:read`
  - `acceptance:run`
- 前端“经营分析”新增“最终验收巡检”面板，可运行巡检、查看评分、打开报告、查看阻断项和下一步动作。

## 巡检覆盖范围

- 登录和企业资料
- 网页客服与会话收件箱
- CRM 线索和跟进任务
- Workflow 自动化
- AI Engine
- Connector 只读入站
- 平台自动发送边界
- 团队权限
- 审计日志
- 计费订阅和用量
- 经营报表
- 客户交付包
- 安全和隐私边界

## 重要边界

巡检不会把未授权平台的自动发送、自动发布、自动改价、退款、发货判定为已完成。对于微信、抖音、淘宝、拼多多、闲鱼等平台，当前交付边界仍是只读入站或草稿辅助，正式自动发送必须取得官方 API 权限并配置验签、审计和人工确认策略。

## 验收方式

1. 登录后台并打开“经营分析”。
2. 点击“运行巡检”。
3. 确认页面出现就绪评分、总体状态和验收项。
4. 打开 Markdown 巡检报告。
5. 按“下一步动作”处理客户真实账号、真实密钥和官方授权。
