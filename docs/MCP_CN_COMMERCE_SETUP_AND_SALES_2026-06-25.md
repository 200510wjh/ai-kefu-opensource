## 它能做什么

`mcp-cn-commerce` 是国内电商经营数据 MCP 连接器，定位是：

```text
让 AI 读取商家经营数据，用来分析订单、商品、退款、广告、库存和评价。
```

覆盖平台：

- 巨量引擎 / 千川
- 抖店
- 京东
- 淘宝
- 拼多多
- 快手
- 小红书
- 微信小店

安全定位：

- 默认只读。
- 不发布商品。
- 不改价。
- 不退款。
- 不发货。
- 不自动回复客户。

这点很适合拿来卖给商家，因为风险比“自动操作后台”低很多。

## 需要客户准备什么

每个客户需要提供对应平台开放平台凭证。

抖店：

```text
DOUDIAN_APP_KEY
DOUDIAN_APP_SECRET
DOUDIAN_SHOP_ID
DOUDIAN_ACCESS_TOKEN
```

京东：

```text
JD_APP_KEY
JD_APP_SECRET
JD_ACCESS_TOKEN
```

巨量引擎 / 千川：

```text
OCEANENGINE_APP_KEY
OCEANENGINE_APP_SECRET
OCEANENGINE_ACCESS_TOKEN
```

如果客户没有开放平台权限，第一版可以先做“手动导表 + AI 分析”，等客户愿意付费后再申请 API 权限。

## 怎么卖给别人

### 目标客户

优先找这三类：

1. **多平台商家**
   - 同时做抖店、淘宝、京东、拼多多。
   - 痛点是每天看很多后台，很累。

2. **代运营团队**
   - 管很多客户店铺。
   - 痛点是日报、周报、异常复盘重复劳动。

3. **本地品牌/小老板**
   - 不懂数据。
   - 只想知道今天哪里有问题、该做什么。

### 首轮话术

```text
我现在做了一个电商 AI 经营助手，不帮你乱改后台，也不自动发东西。
它只读你的经营数据，每天给你出一份老板能看懂的日报：

1. 今天 GMV、订单、退款率怎么样
2. 哪些商品卖得好
3. 哪些商品差评/退款异常
4. 哪些库存快断货
5. 明天运营该先处理什么

你不用每天打开几个平台后台翻数据。
我可以先用你导出的订单/评价表，免费给你做一版样例。
觉得有用再接 API 自动跑。
```

### 第一次成交打法

不要一上来卖“系统”，先卖“报告”。

流程：

```text
客户导出 7 天订单/评价/商品表
-> 你用 AI 生成诊断报告
-> 发给客户看问题
-> 提出每月自动日报/预警服务
-> 再谈 API 接入或私有部署
```

首单价格可以低：

```text
99 元：做一次样例日报
299 元：做一次 7 天店铺诊断
999 元/月：自动日报 + 异常预警
```

### 抖音获客选题

可以发这些视频：

```text
1. 老板别每天翻后台了，AI 自动给你生成电商日报
2. 抖店退款率突然升高，AI 10 秒找出原因
3. 多平台商家最怕什么？库存断货和差评没人看
4. 我用 AI 给一个店铺做了 7 天经营体检
5. 不自动改后台，只帮老板看懂数据，这才是安全的电商 AI
```

## 交付边界

必须和客户说清楚：

```text
我们第一阶段只做只读分析，不做自动发布、改价、退款、发货。
所有建议由人工确认后执行。
```

这样更容易成交，也更安全。
