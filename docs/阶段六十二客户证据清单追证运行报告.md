# 阶段六十二：客户证据清单追证运行

## 目标

阶段六十一让运营能看到客户证据清单收件箱。阶段六十二继续把“看到缺口”推进到“可立即追证”：系统根据当前真实平台验收报告和 Manifest 收件箱，生成客户追证草稿、剩余缺口列表，并可选为缺口场景生成新的客户清单链接。

## 新增能力

- 后端新增 `POST /api/v1/ops/platform-acceptance-manifest-followup-run`。
- 运行会读取当前真实平台验收报告，识别仍未通过的必需场景。
- 运行会读取 Manifest 收件箱，判断每个缺口是等待客户提交、需要重新提交，还是已有预览可进入人工导入复核。
- 可选生成新的 Manifest 清单链接，仅覆盖当前剩余缺口。
- 前端新增 `Manifest follow-up` 按钮，生成后自动复制客户追证草稿。
- 结果区展示缺口、收件箱计数、Manifest 链接、导入预览和提交报告入口。

## 安全边界

- Follow-up run 不登记通过证据。
- 客户提交仍必须先进入导入预览。
- 真实证据导入仍需要运营人工审核，并使用 `CONFIRM_PLATFORM_EVIDENCE` 显式确认。
- 生产只读冒烟会关闭 `create_manifest_link` 和 `include_artifact`，避免额外创建公开链接或报告产物。
