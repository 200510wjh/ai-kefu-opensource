# 阶段三十五：真实平台验收证据包报告

## 目标

把“客户真实账号、官方授权、真实消息/线索场景验收”这些外部条件，纳入系统内可登记、可审计、可交付的证据包，避免只靠口头确认判断平台接入完成。

## 已完成

1. 后端新增证据模型
   - `PlatformAcceptanceEvidenceRequest`
   - `PlatformAcceptanceEvidence`
   - `PlatformAcceptanceReportRequest`
   - `PlatformAcceptanceReport`

2. 后端新增接口
   - `POST /api/v1/ops/platform-acceptance-evidence`
   - `POST /api/v1/ops/platform-acceptance-report`
   - 权限：`settings:write`

3. 证据安全检查
   - 证据登记要求 `no_secrets_confirmed=true`。
   - 拒绝明显包含 `password=`, `token=`, `secret=`, `cookie=`, `authorization=` 等敏感字段的摘要。
   - 只保存脱敏摘要、场景、结果和可选证据链接。

4. 证据包判定
   - 必需场景：
     - `official_auth`
     - `callback`
     - `read_message`
     - `read_lead`
     - `draft_reply`
     - `customer_trial`
   - `ready`：必需场景均有通过证据，且没有失败证据。
   - `partial`：已有部分证据，但仍有缺口或提醒。
   - `blocked`：没有证据或存在失败证据。

5. 前端设置页接入
   - 新增“登记证据”入口。
   - 新增“证据包”入口。
   - 展示最近证据、证据包状态、证据数量和缺失场景。

6. 交付包和验收纳入
   - 交付包新增 `真实平台验收证据包.md`。
   - 验收矩阵新增 `Platform real acceptance evidence`。
   - 最终验收巡检新增“真实平台验收证据包”。

## 安全边界

- 不保存平台密码、token、cookie、验证码或密钥。
- 不自动调用平台发送接口。
- 真实完成仍以客户账号、官方授权、真实消息/线索和脱敏证据为准。

## 验证清单

1. `python -m py_compile backend/customer_service_saas.py backend/api_v1.py backend/main.py`
2. `npm run build`
3. `npm run secret-scan`
4. TestClient 能登记脱敏证据 artifact。
5. TestClient 会拒绝疑似包含 token 的证据。
6. TestClient 能生成真实平台验收证据包 artifact。
7. 交付包包含 `真实平台验收证据包.md`。
8. 最终验收审计包含 `platform_evidence=` 证据。
