# 阶段二十五：平台接入配置向导报告

## 目标

把 OAuth、官方只读 API、Webhook 验签和受控发送留下的 warning，整理成运营可执行的配置任务清单。系统不伪造平台授权，也不回显密钥，只告诉运营负责人还缺什么、下一步做什么。

## 已完成能力

1. 新增后端接入向导：
   - `GET /api/v1/ops/setup-guide`
   - 按 Connector 输出任务：OAuth app 配置、授权回调、token exchange、refresh token、Webhook 签名、官方只读 API、受控发送、健康告警修复。
   - 每个任务包含状态、严重级别、证据、下一步、所需字段、已配置字段和 endpoint 提示。

2. 接入系统设置页：
   - 新增“平台接入配置向导”面板。
   - 汇总已完成、待处理、阻塞任务数量。
   - 逐个平台展示缺口，不展示真实密钥内容。

3. 接入验收体系：
   - 交付包验收矩阵新增 `Platform setup guide`。
   - 最终验收巡检新增“平台接入配置向导”。
   - 当缺少真实官方授权、endpoint 或凭证时保持 warning，不声明已完成真实平台全量接入。

## 交付边界

- 当前能力负责“配置缺口收敛”，不替客户申请开放平台权限。
- 没有真实官方账号、授权回调、访问凭证和 endpoint 时，系统只返回待配置或阻塞任务。
- 受控发送仍要求人工确认、低风险校验、频控和审计。
- 无人值守自动发送、自动发布、自动改价、退款和发货仍不开放。

## 验证清单

1. Python 后端编译通过。
2. 前端 `npm run build` 通过。
3. TestClient 调用 `/api/v1/ops/setup-guide` 能返回任务和计数。
4. 最终验收巡检能看到“平台接入配置向导”。
5. secret scan 通过后再部署。
