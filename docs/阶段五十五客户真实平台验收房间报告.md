# 阶段五十五：客户真实平台验收房间报告

## 目标

阶段五十四已经提供运营侧守护看板。阶段五十五新增客户验收房间，把客户平台负责人需要使用的入口集中到一个短期签名页面：安全配置提交、脱敏材料提交、缺口清单、守护看板和最终签署状态。

## 新增能力

- 新增后台接口：`POST /api/v1/ops/platform-acceptance-customer-room-link`
- 新增公开页面：`GET /api/v1/public/platform-acceptance-customer-room`
- 新增前端入口：系统设置中的“验收房间”按钮。
- 新增交付包文件：`Real-Platform-Customer-Acceptance-Room.md`

## 房间内容

- 当前证据包状态。
- 当前缺口场景数量和清单。
- 脱敏材料提交入口。
- 官方平台安全配置提交入口。
- 最终签署入口；如果门禁未 ready，则显示 blocked。
- 守护看板报告入口。

## 安全边界

- 房间页面只聚合短期签名链接和脱敏状态，不存储密钥。
- 敏感字段仍只能通过安全配置表单进入后端加密存储路径。
- 客户提交材料后不会自动通过验收，仍需要运营复核并由系统复算最终门禁。
- 最终签署仅在所有 required scenarios 都具备可验证 pass evidence 后开放。

## 当前结论

阶段五十五把客户侧动作从多条链接收敛为一个验收房间。客户平台负责人拿到房间链接后，可以按一个页面完成配置补充、材料提交和最终签署查看，运营侧无需反复解释该使用哪个入口。
