# 阶段六十四：客户脱敏证据上传通道

## 目标

阶段六十三解决了证据链接预检问题。阶段六十四继续减少客户交付阻力：当客户没有公开可访问的证据链接时，可以在签名 Manifest 页面直接上传脱敏截图、PDF、文本或文档，系统生成可回填到 Manifest 的证据 URL。

## 新增能力

- 后端新增 `POST /api/v1/public/platform-acceptance-evidence-manifest-upload`。
- 上传端点复用 Manifest 签名 token，并校验场景是否在该 token 允许范围内。
- 支持 `.png`、`.jpg`、`.jpeg`、`.webp`、`.pdf`、`.txt`、`.md`、`.json`、`.csv`、`.docx`。
- 单文件限制 10MB。
- 文本类文件会扫描明显 `password:`、`token:`、`cookie:`、`authorization:` 等密钥模式。
- 上传成功后返回完整 HTTPS `evidence_url`，公共 Manifest 页面会自动填入对应场景 URL 输入框。

## 安全边界

- 上传材料不会登记通过证据。
- 上传后仍需提交 Manifest，生成导入预览。
- 真实导入仍需要运营人工审核，并使用 `CONFIRM_PLATFORM_EVIDENCE` 显式确认。
- 文件上传只允许白名单类型，拒绝空文件、超大文件、明显密钥文本和 token 未授权场景。
