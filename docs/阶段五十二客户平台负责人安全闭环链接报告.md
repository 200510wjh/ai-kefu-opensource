# 阶段五十二：客户平台负责人安全闭环链接报告

## 目标

阶段五十一已经提供后台闭环执行台，但仍需要运营人员把客户平台负责人提供的字段转录到后台。阶段五十二新增短期安全提交链接，让平台负责人可以直接通过 HTTPS 页面提交官方平台配置字段、密钥字段和脱敏试运行材料，系统收到后自动加密保存并复验最终门禁。

## 新增能力

- 新增后台接口：`POST /api/v1/ops/platform-acceptance-owner-closure-link`
- 新增公开页面：`GET /api/v1/public/platform-acceptance-owner-closure`
- 新增公开提交接口：`POST /api/v1/public/platform-acceptance-owner-closure`
- 新增前端入口：系统设置中的“闭环链接”按钮。
- 新增交付包文件：`Real-Platform-Owner-Secure-Closure-Link.md`

## 安全设计

- 链接使用 HMAC token 签名，并设置过期时间。
- 链接可限制允许提交的 connector。
- `client_secret`、`app_secret`、`access_token`、`session_key`、`webhook_token`、`oauth_code`、`api_key` 只通过表单提交到 `secret_fields`。
- 后端复用现有 connector 加密存储路径，只在报告中显示密钥字段名，不显示密钥值。
- 非敏感配置仍会拒绝明显密钥字段，避免把 token 或 secret 写进普通配置、文档或审计报告。
- 提交后自动运行阶段五十一闭环执行台，最终签署门禁仍以真实可验证证据为准。

## 当前结论

阶段五十二把剩余外部阻塞转成可在线完成的客户动作：客户平台负责人拿到链接后，可以直接提交官方授权参数、只读接口配置和脱敏试运行材料。系统侧已经具备自动加密、自动复验和自动生成最新闭环报告的能力。
