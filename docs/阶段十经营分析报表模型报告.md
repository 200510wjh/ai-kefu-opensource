# 阶段十 经营分析报表模型报告

生成时间：2026-07-16

## 一、阶段目标

本阶段目标是让经营分析从“指标展示”升级为“可生成、保存、复盘的经营报表”。

## 二、本阶段完成内容

### 1. 新增报表模型

修改文件：

- `backend/customer_service_saas.py`

新增模型：

- `BusinessReport`
- `ReportGenerateRequest`

新增表：

- `business_reports`

### 2. 新增报表接口

修改文件：

- `backend/api_v1.py`
- `backend/platform/security.py`

新增接口：

- `GET /api/v1/reports`
- `POST /api/v1/reports/generate`

新增权限：

- `reports:read`
- `reports:write`

### 3. 日报生成逻辑

日报内容基于真实数据生成：

- 企业概览
- CRM 概览
- 高意向线索
- Connector 授权状态
- 打开中的跟进任务
- 订阅和用量额度
- 建议动作

生成报表会同时写入：

- `business_reports`
- `usage_records`
- `audit_logs`

### 4. 前端经营分析接入

修改文件：

- `src/main.tsx`

经营分析页新增：

- 经营报表列表
- 生成日报按钮
- 报表摘要展示

## 三、安全边界

报表只使用系统内已有数据，不抓取外部平台未授权数据。

没有 Connector 授权时，报表只显示授权状态和待办建议，不伪造平台经营数据。
