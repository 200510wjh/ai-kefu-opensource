# 阶段二十九：平台接入任务复验关闭报告

## 目标

第 28 阶段已经能把平台接入干跑中的缺口同步到 CRM 任务。本阶段补齐闭环：客户或技术负责人补齐官方授权、endpoint、Webhook 签名材料后，运营可以重新干跑，并自动关闭已经通过的接入任务。

## 已完成能力

1. 新增后端复验模型：
   - `IntegrationTaskReconcileRequest`
   - `IntegrationTaskReconcileResult`

2. 新增后端接口：
   - `POST /api/v1/ops/integration-task-reconcile`
   - 重新运行平台接入干跑验收。
   - 对 dry run 已 `pass` 的检查项，关闭匹配的 open CRM 任务。
   - 对仍 `fail/warning` 的检查项保持任务打开。

3. 幂等和边界：
   - 复验只更新 `source=integration_dry_run` 的 open 任务。
   - 复验不调用真实平台 endpoint。
   - 复验不发送消息、不发布商品、不改价、不退款、不发货。

4. 前端系统设置页接入：
   - “平台接入配置向导”面板新增“复验关闭”按钮。
   - 显示已关闭任务、仍打开任务、剩余检查数量。
   - 复验后刷新 CRM 任务列表。

5. 验收接入：
   - 验收矩阵新增 `Platform integration task reconcile`。
   - 最终验收巡检新增“平台接入任务复验关闭”。

## 验证清单

1. Python 编译通过。
2. 前端 `npm run build` 通过。
3. TestClient 能调用复验接口。
4. 复验接口不会关闭仍未通过的任务。
5. 最终验收巡检包含复验关闭证据。
6. secret scan 通过后部署。
