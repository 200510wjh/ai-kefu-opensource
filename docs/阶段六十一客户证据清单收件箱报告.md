# 阶段六十一：客户证据清单收件箱

## 目标

把阶段六十的客户真实平台证据清单提交页，接到运营侧的收件箱。运营人员可以看到客户是否提交、哪些提交已经可进入人工导入复核、哪些仍需客户补证。

## 新增能力

- 后端新增 `POST /api/v1/ops/platform-acceptance-evidence-manifest-inbox`。
- 收件箱从审计日志读取 `integration.platform_acceptance_evidence_manifest_submission`，兼容阶段六十以前的简版记录。
- Manifest 提交审计元数据新增场景、缺口、提交报告、导入预览、回执和复核任务同步 ID。
- 前端验收配置区新增 `Manifest inbox` 按钮。
- 结果区展示提交总数、可导入数量、需客户修正数量，并提供提交报告和导入预览报告入口。

## 安全边界

- 收件箱只汇总客户提交，不登记通过证据。
- 客户提交仍先生成 `execute=false` 的导入预览。
- 真实证据导入仍需要运营人工检查，并使用 `CONFIRM_PLATFORM_EVIDENCE` 显式确认。
- 占位链接、疑似密钥或不合规材料仍由导入预览阻断。
