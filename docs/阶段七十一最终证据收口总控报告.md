# 阶段七十一：最终证据收口总控报告

## 目标

阶段七十已经能把客户 Manifest 重提转成 CRM 催办任务。阶段七十一新增最终收口总控，把自动守护、客户房间、客户重提追踪、催办任务、最终签署门禁和验收报告重新计算串成一次运行，作为“全部完成”前的最后真实证据收口动作。

## 已完成

- 新增 `POST /api/v1/ops/platform-acceptance-final-closure-run`。
- 总控运行会依次执行：
  - 当前真实平台验收报告
  - Manifest 重提 tracker
  - Manifest 重提催办任务包
  - 平台验收 auto watch
  - 客户验收房间
  - 最终签署门禁
  - 收口后验收报告
- 前端新增 `Final closure` 总按钮。
- 前端新增总控结果面板，展示缺口前后、任务创建/复用、安全链接数量、总控 artifact。
- 总控报告不直接写入签名客户 URL，只保留内部 artifact 和状态摘要。

## 安全边界

- 总控不会伪造证据。
- 只有真实 connector 授权/只读拉取成功时，既有 connector 例程才可能登记 pass evidence。
- 客户提交材料仍必须人工审核、URL 预检，并通过 `CONFIRM_PLATFORM_EVIDENCE` 执行导入。
- 最终签署门禁只有在真实报告无缺口时才会变为 ready。
