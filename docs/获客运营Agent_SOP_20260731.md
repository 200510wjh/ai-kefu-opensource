## 1. 目标

把现有“运营项目”收束成一个真正能跑日常获客闭环的 Agent：

```text
峰会/市场/公开线索
-> 需求判断
-> 抖音/闲鱼/朋友圈内容草稿
-> 视频生产
-> 人工审核发布
-> 私信/评论/表单承接
-> CRM 跟进
-> 数据回填
-> 每周复盘迭代
```

这个 Agent 的定位不是“自动群发工具”，而是你的个人 IP 和企业客户获客操作系统。它负责把信息、素材、脚本、视频、发布草稿、客服候选回复、CRM 跟进和复盘串起来，敏感动作停在人工确认。

### 3.4 抖音发布 SOP

1. 每天从峰会图、项目进展、客户痛点里选 1 个主题。
2. 用 ContentAgent 生成 15s/30s/60s 脚本。
3. 用 HyperFrames 或 Remotion 出竖屏视频。
4. 自动生成标题、封面字、字幕、标签。
5. 进入发布审核记录，状态为 `review`。
6. 人工检查：不能虚假承诺，不能说“全自动替你成交”，必须强调先试点、可交付。
7. 使用发布面板或 `social-auto-upload` 发起上传。
8. 最终点击发布必须人工确认。
9. 发布后 2 小时、24 小时、72 小时回填播放、收藏、评论、私信、成交。

## 5. 真正 Agent 的模块设计

Agent 名称建议：

```text
SoloGrowthAgent
一人 AI 获客运营 Agent
```

### 5.1 Agent 必备能力

一个真正 Agent 至少要有：

- 目标：每天帮助你获得企业客户线索。
- 记忆：需求、素材、内容、发布记录、线索、互动、成交数据。
- 工具：生成内容、生成视频、创建发布草稿、打开发布面板、分析私信、创建 CRM 任务。
- 规划：根据当天目标决定先做什么。
- 执行：调用工具生成草稿或启动任务。
- 审计：记录每次工具调用和结果。
- 安全边界：外发、发布、私信、交易都需要人工确认。
- 复盘：根据数据决定明天发什么。

### 5.2 Agent 分工

```text
MarketAgent
扫描峰会素材、公开平台、客户反馈，生成需求信号。

ContentAgent
把需求信号生成抖音、闲鱼、朋友圈内容草稿。

VideoAgent
把脚本转成 HyperFrames/Remotion 视频任务。

PublishAgent
管理发布审核队列，调用 MPAU/social-auto-upload/Automa 进入上传流程。

LeadAgent
把评论、私信、表单、闲鱼咨询整理成 CRM 线索。

SalesAgent
分析聊天记录，判断意向等级，生成下一步回复和跟进任务。

ReviewAgent
回填数据，生成日复盘和周复盘。
```

### 5.3 工具边界

P0 工具：

- `run_daily_growth_workflow`：运行每日获客流程。
- `create_public_prospect_search`：生成公开平台搜索入口。
- `import_public_prospect_candidate`：导入人工核实的公开客户证据。
- `generate_contact_suggestion`：生成触达建议。
- `create_followup_task`：创建人工跟进任务。

需要新增的工具：

- `generate_summit_content_pack`：从峰会照片/笔记生成 10 条选题、脚本、封面文案。
- `create_video_render_job`：根据脚本创建 HyperFrames/Remotion 出片任务。
- `create_douyin_publish_draft`：把视频、标题、文案、标签放入发布队列。
- `create_xianyu_listing_draft`：生成闲鱼服务商品草稿。
- `open_publish_panel`：打开本地发布面板，停在人工确认。
- `backfill_publish_metrics`：回填播放、收藏、评论、私信、成交。
- `weekly_growth_review`：根据数据产出下周选题和销售动作。

禁止自动执行：

- 自动私信陌生客户。
- 自动群发。
- 自动发布商品。
- 自动改价。
- 自动发货。
- 自动提交付款、退款或敏感表单。

## 7. 30 天执行计划

### 第 1 周：打通最小闭环

目标：每天至少 1 条抖音、1 个闲鱼服务商品草稿、1 次数据回填。

每天流程：

```text
09:00 选一个峰会/客户痛点主题
09:20 生成抖音脚本和闲鱼商品草稿
10:00 制作或复用视频
11:00 人工审核并发布抖音
14:00 检查评论/私信/闲鱼咨询
18:00 创建 CRM 线索和跟进任务
22:00 回填播放、咨询、成交数据
```

验收：

- 7 条抖音视频。
- 3-5 个闲鱼服务商品/帖子。
- 至少 10 条评论/私信/公开咨询记录被手动录入。
- 每条发布记录有数据回填。

### 第 2 周：内容 A/B 测试

测试三类内容：

- 峰会观察类：证明你在真实学习企业 AI。
- 项目纪录片类：展示你一个人用 AI 做系统。
- 结果交付类：展示 AI 客服、知识库、CRM、工作流能解决什么。

验收：

- 找出播放/私信最高的 3 个标题模板。
- 找出咨询质量最高的平台。
- 形成 1 个可复用视频模板。

### 第 3 周：线索承接

重点不是继续多发，而是把咨询接住：

- 私信统一打标签：老板/同行/白嫖/企业客户/代理商。
- 每个高意向线索必须有下一步动作。
- SalesAgent 生成候选回复，人工发送。
- 建一个“企业 AI 试点诊断表”。

验收：

- 20 个有效线索。
- 5 个高意向沟通。
- 1-2 个试点报价。

### 第 4 周：产品化

把重复交付整理成三个可卖产品：

```text
99 元：AI 获客诊断
999 元：企业 AI 客服/知识库试点
4999 元起：AI Agent + CRM + 自动化工作流搭建
```

验收：

- 1 个成交或明确报价机会。
- 1 套标准交付清单。
- 1 个客户案例视频。

## 10. 核心原则

```text
内容自动生成，但观点要真实。
视频可以自动做，但发布要人工确认。
客服可以生成候选，但外发要人工确认。
公开线索可以整理，但不能骚扰。
Agent 要能赚钱，必须回填数据。
```

这套 Agent 的核心不是“让 AI 替你点按钮”，而是让你每天知道：今天发什么、发到哪里、谁咨询了、下一步跟进什么、哪类内容能带来企业客户。
