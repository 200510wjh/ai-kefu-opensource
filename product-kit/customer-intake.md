# 客户资料收集表

用于成交前诊断和成交后交付。发给客户时可以复制到微信、飞书或腾讯文档。

## 基础信息

- 店铺名称：
- 联系人：
- 微信 / 手机：
- 主营类目：
- 主要平台：抖店 / 淘宝 / 天猫 / 京东 / 拼多多 / 小红书 / 快手 / 其他
- 当前月销售额区间：
- 当前团队人数：

## 当前最想解决的问题

请选择 1-3 个：

- 看不懂后台数据
- 不知道哪个商品该推
- 退款 / 差评变多
- 客服回复慢
- 投放花钱但不赚钱
- 库存经常断货
- 多个平台数据太散
- 老板每天没有经营汇总

## 需要客户提供的资料

先做 99 元体检或 299 元试用时，只需要截图，不需要 API。

1. 近 7 天店铺核心数据截图：GMV、订单、退款、访客、转化率。
2. 商品销量排行截图。
3. 退款原因或售后截图。
4. 差评 / 中评截图。
5. 当前正在主推的 3 个商品链接或截图。
6. 如果有投放，提供消耗、ROI、成交截图。

## 授权说明

如果客户购买月费服务，需要后续接入平台 API 或授权后台导出。前期原则：

- 只读数据。
- 不自动改价。
- 不自动发货。
- 不自动退款。
- 不自动发布商品。
- 所有经营建议由客户确认后执行。
