# 交付 SOP

## 成交前

1. 给客户看 `index.html` 演示页或 `sample-daily-report.md`。
2. 让客户填写 `customer-intake.md`。
3. 收取 99 元体检或 299 元 7 天试用费用。
4. 建一个客户文件夹：`客户名_AI店铺日报`。

## 99 元体检交付

交付时间：24 小时内。

交付内容：

1. 店铺核心问题判断。
2. 商品表现分析。
3. 差评 / 退款原因。
4. 3 条可执行优化建议。
5. 是否建议进入 7 天陪跑。

交付格式：

```text
《客户名_AI店铺体检报告_日期》
```

## 299 元 7 天陪跑

每天固定收集：

1. GMV、订单、客单价、退款率。
2. 商品销量排行。
3. 差评 / 售后截图。
4. 客服高频问题。
5. 库存或投放异常。

每天固定交付：

1. 今日核心结论。
2. 数据变化。
3. 商品建议。
4. 售后建议。
5. 明日行动清单。

第 7 天额外交付：

1. 7 天复盘。
2. 店铺主要增长机会。
3. 是否建议转月费。

## 999 元月费服务

固定交付：

- 每日经营日报：每天 1 份。
- 每周复盘报告：每周 1 份。
- 差评 / 退款预警：发现异常当天提醒。
- 商品优化建议：每周整理 3-5 条。
- 客服话术建议：按问题类型更新。

## 客户沟通节奏

每天上午：

```text
老板，今天日报我会在下午前发你。你先把昨天后台核心数据、商品排行、退款和差评截图发我。
```

每天下午交付：

```text
老板，今天的 AI 经营日报好了。重点看第 1 部分和第 5 部分，今天最该处理的是退款率上升的 SKU。
```

第 7 天升级：

```text
这 7 天主要问题已经很清楚了：退款集中在尺码和色差，爆品也有了方向。后面如果继续做，我建议转月费版，每天盯数据，每周做一次复盘。
```

## 注意事项

- 不承诺一定提升销售额，只承诺持续发现问题和给动作建议。
- 不代替客户做财务、法务、税务决策。
- 没有客户确认，不自动发布商品、不改价格、不退款。
- 客户截图和密钥不能发到公开群或仓库。
