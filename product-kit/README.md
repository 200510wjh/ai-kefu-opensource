# AI 店铺经营日报成品包

这是一个可以直接拿去卖给商家的轻量成品包。它不是卖技术名词，而是把服务包装成商家能理解、能付钱的结果：

> 每天一份老板看得懂的经营日报，告诉他哪里赚钱、哪里漏钱、明天先改什么。

## 文件说明

- `index.html`：客户演示页，直接双击打开即可展示。
- `sample-daily-report.md`：样例经营日报，可发给客户预览。
- `customer-intake.md`：客户资料收集表，成交前后都能用。
- `sales-script.md`：私信、电话、朋友圈、成交话术。
- `delivery-sop.md`：7 天试用和月费服务交付流程。

## 推荐售卖路径

1. 发演示页或样例日报给商家。
2. 让商家发后台截图，先做一份 99 元体检报告。
3. 引导购买 299 元 7 天 AI 经营陪跑。
4. 有效果后升级到 999 元/月 AI 店铺运营助理。

## 价格包装

| 套餐 | 价格 | 交付 |
| --- | ---: | --- |
| AI 店铺体检报告 | 99 元/份 | 一次性诊断报告 |
| 7 天 AI 经营陪跑 | 299 元/7 天 | 每天 1 份日报 + 优化建议 |
| AI 店铺运营助理 | 999 元/店/月 | 日报、周报、差评退款预警、商品建议 |
| 多平台经营看板 | 1999 元/月起 | 抖店/淘宝/京东/拼多多多店汇总 |

## 交付边界

前期可以用截图和导出表手工交付，先验证需求和收钱。客户稳定后，再接入 `mcp-cn-commerce`，通过平台 API 自动读取真实数据。
