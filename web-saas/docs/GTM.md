# 抖音引流 + 开源获客计划

## 定位

商剪增长画布帮助本地商家、电商卖家和 AI 代理商把一句需求变成短视频、主图详情、客服话术和线索承接流程。

## 三个版本

- 本地商家版：同城短视频、活动分镜、留资表单、预约 CTA。
- 电商卖家版：主图、详情图、商品短视频、客服话术。
- 代理商/开发者版：开源画布、私有化部署、二开模板、API 服务。

## 30 天内容测试

- 每天 3 条短视频，测试“AI 生成商家方案”“老板发一句话出分镜”“电商一套素材生成”。
- 每条视频都引导到企业号私信、线索表单或 GitHub。
- 核心指标：主页访问、私信数、表单数、试用注册、GitHub Star、部署咨询。

## 收费路径

- Starter：99 元/月，30 次生成。
- Pro：299 元/月，150 次生成。
- Agency：999 元/月起，团队账号、模板库和私有化部署咨询。

## 第一个月验收

- 10 个试用商家。
- 3 个付费订阅或 1 个代理商定制单。
- 60-90 条抖音内容。
- GitHub 仓库可公开运行，有截图、演示和部署文档。
