## 和当前电商自动化产品的关系

它适合接在商品上架自动化后面：

```text
商品资料
-> AI 商品上架草稿
-> 标题/卖点/SKU/详情页
-> 口播脚本
-> 口播视频剪辑
-> 抖音/小红书商品种草素材
```

## 可售卖包装

### 299 元：单品上架素材包

- 商品标题
- 商品卖点
- 详情页结构
- SKU 表
- 客服 FAQ
- 1 条口播视频脚本

### 499 元：单品上架 + 口播成片包

- 上架素材包全部内容
- 1 条口播剪辑成片
- 3 条短视频标题
- 3 条发布文案

### 999 元：10 个商品批量上架草稿

- 10 个商品标题/卖点/SKU/详情草稿
- 每个商品 1 条口播脚本
- 适合店铺批量上新

### 2999 元起：月度商品内容代运营

- 每月商品上新草稿
- 每周口播素材剪辑
- 商品日报/退款差评分析
- 人工确认后再发布

## 安全边界

- 只生成草稿和素材。
- 不自动发布商品。
- 不自动改价。
- 不自动退款。
- 不自动发货。
- 平台后台动作必须人工确认。
