# 交付审计与记忆点

更新时间：2026-06-25

## 必须长期记住的产品原则

1. 不要做只有文案的工具。客户要真实图片、真实视频、AI客服、线索和订阅。
2. 按钮能点不等于功能完成。每个按钮背后必须有真实 API、状态反馈、错误提示和数据落库。
3. 页面有数据不等于系统可用。刷新、重启、换浏览器后还在，才算真实数据。
4. 登录成功不能是假状态。必须有账号、商户、会话、权限和后台可见记录。
5. 订阅不能只是套餐卡片。必须有订单、套餐、额度、到期时间、使用记录和后台管理。
6. 出图出视频不能只给 prompt 或 JSON。正式卖给客户时，必须能生成真实图片文件和真实 MP4。
7. 客户不用 Codex 插件。Codex 插件是开发和运营工具；客户使用 SaaS 网页或抖音小程序。
