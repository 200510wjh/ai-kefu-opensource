# GEO 智能体首单交付 SOP

## 目标

用最轻的方式完成第一批付费交付。

首单不要追求全自动平台，先追求：

- 客户愿意付费
- 报告能看懂
- 建议能执行
- 下个月能复测

## 交付周期

建议 2-3 天完成一单。

```text
第 1 天：收集资料 + 生成问题库 + 跑 AI 采样
第 2 天：诊断分析 + 生成报告
第 3 天：讲解报告 + 推月度服务
```

## 客户资料收集表

让客户填写：

- 公司/品牌名称
- 官网链接
- 主营业务
- 目标客户是谁
- 服务城市或区域
- 3-5 个竞品
- 最想被客户搜索到的关键词
- 最担心 AI 说错的内容
- 过去做过哪些 SEO/内容/投放
- 是否有案例、资质、媒体报道、客户评价

## 问题库模板

每个客户至少准备 50 个问题，分成 6 类。

### 1. 行业推荐类

```text
哪家公司适合做 {行业服务}？
{城市} 哪家 {服务} 比较靠谱？
中小企业适合选哪家 {产品/服务}？
```

### 2. 品牌认知类

```text
{品牌名} 是做什么的？
{品牌名} 靠谱吗？
{品牌名} 适合什么类型的客户？
```

### 3. 竞品对比类

```text
{品牌名} 和 {竞品名} 有什么区别？
{竞品 A}、{竞品 B}、{品牌名} 哪个更适合中小企业？
```

### 4. 购买决策类

```text
选择 {服务} 时应该看哪些指标？
{行业服务} 一般多少钱？
第一次做 {服务} 应该避开哪些坑？
```

### 5. 场景需求类

```text
我是 {客户类型}，想解决 {具体问题}，适合找哪家公司？
{城市} {客户类型} 做 {服务} 有什么推荐？
```

### 6. 风险质疑类

```text
{品牌名} 有没有负面评价？
{品牌名} 的服务有什么缺点？
{行业服务} 常见骗局有哪些？
```

## 采样记录表字段

建议用表格记录：

| 字段 | 说明 |
| --- | --- |
| 问题 | 原始提问 |
| 平台/模型 | ChatGPT、豆包、Kimi、DeepSeek 等 |
| 是否提到客户品牌 | 是/否 |
| 客户品牌位置 | 第几个出现 |
| 是否提到竞品 | 是/否 |
| 竞品列表 | 出现了哪些竞品 |
| 回答倾向 | 正向/中性/负向 |
| 是否有错误 | 是/否 |
| 错误内容 | 具体错在哪里 |
| 引用来源 | 有引用则记录链接 |
| 优化建议 | 应该补什么内容 |

## 报告结构

正式报告建议按这个结构：

1. 执行摘要
2. 本次测试范围
3. AI 可见度得分
4. 品牌出现率
5. 竞品出现率
6. 错误信息清单
7. AI 对品牌的常见描述
8. AI 为什么推荐竞品
9. 官网内容缺口
10. 第三方信息源缺口
11. 30 天优化清单
12. 下次复测计划

## GEO 评分规则

可以先用 100 分制，方便客户理解。

| 维度 | 分值 |
| --- | ---: |
| 品牌出现率 | 25 |
| 品牌描述准确率 | 20 |
| 竞品对比优势表达 | 15 |
| 官网内容完整度 | 15 |
| 第三方可信来源 | 15 |
| 负面/错误信息风险 | 10 |

评分解释：

- 80-100：AI 可见度较好，重点做复测和局部增强
- 60-79：有基础，但内容缺口明显
- 40-59：AI 对品牌理解不稳定，容易被竞品压制
- 0-39：AI 基本不理解或不提到品牌，需要补基础资产

## 内容处方清单

每单至少给客户 10 条内容处方。

常见处方：

- 官网首页补一句清晰定位
- 增加“适合哪些客户/不适合哪些客户”
- 增加和竞品的客观对比页
- 增加真实客户案例
- 增加服务流程页
- 增加价格或预算说明
- 增加 FAQ
- 增加城市/区域服务页
- 增加创始人和团队可信信息
- 增加第三方平台品牌介绍
- 修复全网名称不一致问题
- 为核心页面增加结构化数据

## 交付后转月费

报告讲解最后不要只问“要不要继续做”，要给明确路径。

```text
这次体检证明了 3 个问题：
1. AI 在这些问题里没有稳定提到你
2. 竞品在几个关键问题里更容易被推荐
3. 你的官网缺少几类 AI 容易引用的信息

下一步建议做 30 天优化。
我们每周复测一次，边改内容边看 AI 回答有没有变化。
```

## 首月服务交付

首月不需要承诺大结果，承诺过程和可验证产物。

每周节奏：

- 第 1 周：修正品牌实体信息和首页定位
- 第 2 周：补 FAQ、案例、服务流程
- 第 3 周：补竞品对比页和场景方案页
- 第 4 周：复测、月报、下月计划

## 内部质检清单

交付前检查：

- 是否覆盖客户核心业务
- 是否覆盖竞品
- 是否有原始 AI 回答证据
- 是否指出具体错误
- 是否给出可执行页面建议
- 是否有 30 天路线
- 是否明确不承诺排名
- 是否有下一步月度服务方案
