# 不要混在一起做：分批落地路线

当前项目要拆成 4 个可卖模块，不能继续全部塞进一个页面。

## 第 1 批：监听式 AI 客服

目标：先做最容易成交、最贴近你视频样例的产品。

功能：
- 监听聊天内容。
- 判断最后一条客户消息是否未回复。
- 自动生成不傻的回复。
- 支持人工确认、自动粘贴、白名单窗口。
- 后续接企业微信/微信客服/抖音私信官方 API 后，再做无人值守自动发送。

当前已做：
- `/api/customer-service/chat-reply-agent`
- `scripts/desktop_reply_assistant.py`
- `scripts/desktop_auto_reply_listener.py`
- `npm run desktop:reply`
- `npm run desktop:listen`

还没做：
- 企业微信/微信客服官方 API。
- 抖音私信官方 API。
- OCR 截图监听。
- 商户知识库 RAG。
- 多商户后台登录和会话列表。

## 第 2 批：一键生成商品图

目标：做电商卖家能看懂的东西，不只出 prompt。

功能：
- 主图生成。
- 场景图生成。
- 详情页模块图生成。
- 商品卖点自动提取。
- 图片保存到作品库。

真实接入方式：
- API2D/OpenAI-compatible 图片接口。
- 或阿里云/火山/即梦/可灵等图片模型。
- 图片必须落对象存储，例如 OSS/R2/S3。

不能再停留在：
- 只返回 prompt。
- 页面刷新图片丢失。
- 没有商户归属。

## 第 3 批：真实短视频生成

目标：真的输出 1080x1920 MP4。

推荐路线：
- 脚本和分镜：现有 FastAPI 生成。
- 模板渲染：Remotion worker。
- 炫彩 HTML 动效：HyperFrames/GSAP 生成素材或片段。
- 最终合成：Remotion 或 FFmpeg。
- 数字人口播：HeyGen API，可选，不放 MVP 必须项。

MVP 只做：
- 3 个模板。
- 每个模板 15-30 秒。
- 9:16 MP4。
- 字幕。
- 背景音乐。
- 可下载。

不能再停留在：
- JSON artifact。
- 假进度条。
- 没有 MP4 文件。

## 第 4 批：SaaS 后台和订阅

目标：客户能登录、订阅、用额度，你后台能看见。

功能：
- 商户注册/登录。
- 商户空间。
- 员工账号。
- 线索列表。
- 聊天记录。
- 生成任务。
- 作品库。
- 套餐/订单/额度。
- 管理后台看所有商户。

当前真实状态：
- 服务器已有 MySQL `ai_saas`，里面有 merchants、orders、customers、conversations、knowledge_base 等表。
- 当前商家画布新功能先落 SQLite，路径：`/opt/merchant-growth-canvas/data/merchant_growth.sqlite3`。
- 下一步应该把 SQLite MVP 迁到服务器 MySQL，接真实登录和商户隔离。

## 现在不要做的事

- 不要先做完整剪映式编辑器。
- 不要把图片、视频、客服、订阅全堆一个页面。
- 不要说插件已经接入，除非它能被后端真实调用并产生文件或消息。
- 不要用“按钮能点”冒充“功能完成”。

## 可以卖的第一版话术

先卖“AI 客服辅助成交系统”：

> 老板不用自己想怎么回客户，系统自动识别客户最后问了什么，生成不尴尬的回复，帮你少漏线索、少傻回复。前期人工确认发送，后期可接企业微信/微信客服官方 API 做自动化。

图片和视频是第二、第三批，不要抢第一批的交付节奏。
