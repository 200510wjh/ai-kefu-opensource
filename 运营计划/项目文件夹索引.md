## 不建议复制的东西

不要把这些直接打包给客户：

- `node_modules`
- `.env`
- API Key
- 服务器密码
- Codex 内部插件配置

客户要的是 SaaS 账号、网页、小程序或私有部署包，不是你的开发环境。
