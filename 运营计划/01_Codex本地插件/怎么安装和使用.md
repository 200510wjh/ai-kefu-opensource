# Codex 本地插件怎么安装和使用

## 已经创建好的插件

插件名称：

```text
merchant-growth-saas
```

插件目录：

```text
C:\Users\Administrator\plugins\merchant-growth-saas
```

个人插件市场文件：

```text
C:\Users\Administrator\.agents\plugins\marketplace.json
```

## 这个插件是什么

这是给你自己用的 Codex 本地插件，不是卖给客户的 SaaS。

它里面包含一个技能：

```text
merchant-growth-saas-skill
```

作用是让 Codex 能直接帮你处理：

- 商家需求接入
- AI客服
- 图片生成 API
- 视频生成 API
- 抖音小程序 SaaS
- 客户交付
- 部署排查

## 怎么在 Codex 里用

重启 Codex 后，可以直接说：

```text
用商家 AI 增长中台插件，帮我接入一个商家需求
```

或者：

```text
用 merchant-growth-saas-skill 检查 AI客服、出图、出视频和抖音小程序订阅流程
```

## 怎么打包给自己或团队用

打包的是 Codex 插件文件夹：

```text
C:\Users\Administrator\plugins\merchant-growth-saas
```

别人要用时，放到对方电脑：

```text
用户目录\plugins\merchant-growth-saas
```

并把 marketplace.json 加到：

```text
用户目录\.agents\plugins\marketplace.json
```

然后重启 Codex。

## 注意

普通客户不需要这个插件。

客户买的是 SaaS 系统，不是 Codex 插件。
