# 图片和视频真实接入路线

目标：不要只生成文案、prompt、JSON；要真的生成图片文件和 MP4。

## 图片生成

### 第一版接 API2D/OpenAI-compatible

后端需要环境变量：

```text
IMAGE_BASE_URL=https://oa.api2d.net/v1/images/generations
IMAGE_API_KEY=你的 Key
IMAGE_MODEL=可用图片模型名
```

验收标准：
- `/api/images/generate` 返回 `mode=image`。
- 有 `image_url` 或 `artifact_url`。
- 图片能打开。
- 刷新页面后作品库还能看到。
- 后台能看到属于哪个商户、消耗多少额度。

### 第二版接对象存储

图片不能只放第三方临时 URL。

需要：
- 阿里云 OSS / Cloudflare R2 / S3。
- `artifacts` 表。
- `usage_records` 表。
- 失败重试。

## 视频生成

### 推荐架构

```text
商家需求
 -> 脚本/分镜
 -> 模板选择
 -> 素材生成或上传
 -> Remotion/HyperFrames 渲染
 -> FFmpeg 合成/压缩
 -> OSS/R2/S3
 -> 作品库下载
```

### Remotion 怎么用

Remotion 适合：
- React 程序化视频。
- 9:16 品牌模板。
- 字幕动画。
- 批量变体。
- 输出 MP4。

需要做：
- 新建独立 worker 服务。
- 接收 scenes JSON。
- 调用 `renderMedia` 输出 MP4。
- 生成任务状态写数据库。
- 输出文件上传对象存储。

注意：
- 商业 SaaS 要确认 Remotion 授权条件。

### HyperFrames 怎么用

HyperFrames 适合：
- 炫彩 HTML/GSAP 动效。
- 作品集风格动效页。
- 动态字幕片段。
- 把网页视觉转视频片段。

推荐用法：
- 做模板动画和片头。
- 输出 render plan。
- 后续接 CLI/worker 生成视频片段。

不要只在页面展示“HyperFrames 已接入”，必须能输出可用文件。

### HeyGen 怎么用

HeyGen 适合：
- 数字人口播。
- 商家讲解视频。
- 销售跟进视频。

MVP 不要强依赖 HeyGen：
- 先做无数字人的商品/门店短视频。
- 有客户愿意付费，再接 HeyGen 数字人口播。

需要：
- `HEYGEN_API_KEY`
- `HEYGEN_AVATAR_ID`
- HeyGen 任务状态轮询。
- 视频文件沉淀到作品库。

## 第一版视频模板

先只做 3 个模板：

1. 本地商家同城引流
   - 门店/活动/优惠
   - 15-20 秒
   - CTA：私信/到店/预约

2. 电商商品短视频
   - 商品图/卖点/使用场景
   - 20-30 秒
   - CTA：下单/领券/咨询

3. AI 客服成交案例
   - 问题 -> 自动回复 -> 线索沉淀
   - 15 秒
   - CTA：试用系统

## 视频验收标准

每个生成任务必须有：
- 真实 MP4。
- 1080x1920 或 720x1280。
- 可播放。
- 有字幕。
- 有音频或明确静音。
- 有下载链接。
- 数据库有任务记录。
- 失败能看到错误原因。
