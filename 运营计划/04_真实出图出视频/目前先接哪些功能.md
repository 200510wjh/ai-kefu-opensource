# 真实出图出视频目前先接哪些功能

你不想做生成文案，这个判断是对的。

要做能卖的东西，必须能出真实图片和真实视频。

## 真实图片先接

优先做三类图：

1. 商品主图
2. 场景图
3. 详情页模块图

后端配置：

```text
IMAGE_BASE_URL
IMAGE_API_KEY
IMAGE_MODEL
```

可以先用 API2D 或官方图片模型。

页面上要让客户看到：

```text
上传商品图/填写卖点
-> 生成主图
-> 生成详情图
-> 下载
```

## 真实视频分三条线

### 1. 模板短视频

适合：

- 商品卖点视频
- 门店促销视频
- SaaS 功能演示视频

优先接：

```text
Remotion 或 HyperFrames
```

输出：

```text
1080x1920 MP4
```

### 2. 数字人口播视频

适合：

- SaaS讲解
- 课程介绍
- 老板口播
- 产品说明

优先接：

```text
HeyGen
```

需要：

```text
HEYGEN_API_KEY
HEYGEN_AVATAR_ID
```

### 3. 客户给口播视频，你帮他剪成片

适合：

- 老板自己录视频
- 课程老师录屏
- 产品演示录屏

优先接：

```text
口播剪辑 Skills
```

需要：

```text
FFmpeg
VOLCENGINE_API_KEY
```

## 现在最该先做哪个

先做：

```text
图片生成 + 模板短视频
```

原因：

- 最容易演示
- 最容易卖
- 成本可控
- 不依赖客户自己拍视频

再做：

```text
口播剪辑 + HeyGen数字人
```
