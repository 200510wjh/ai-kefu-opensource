## 先测哪几个

当前项目不要一起乱测，按下面顺序来：

1. 线上后台 SaaS：确认网站能打开、登录、核心 API 可用。
2. 商品媒体工厂：拍一张商品图，生成商品主图、详情图、商品短视频。

4. 抖音小程序：确认小程序代码结构和 API 调用是否正常。
5. 桌面客服脚本：确认脚本能启动、能生成回复；自动发送只在测试号里做。
6. 运营交付包：确认 PPT、PDF、Excel、SOP 文件都能打开。
7. GitHub 开源仓库：确认没有密钥、README 可读、能构建，再考虑提交。

1. 旧的 `/api/images/generate` 当前线上返回的是 prompt 模式，没有真实图片 URL，不能当成真正生图卖点。
2. 商品媒体工厂已经能出真实 SVG 和 MP4，这是现在最适合展示的“实物产出”功能。
3. 旧视频渲染 `/api/render` 仍偏演示任务，真正可看的视频要走 `/api/product-media/pack`。
4. 订阅、支付、额度、订单还没做成完整生产闭环。
5. 微信、抖音、淘宝、拼多多、闲鱼自动回复不能靠乱点窗口长期商用，要补官方 API 或服务市场授权。
6. 当前没有可用的桌面控制工具暴露给 Codex，所以我不能真实替你点击桌面验收，只能做命令、接口、构建和产物级测试。
