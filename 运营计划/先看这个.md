# 先看这个

你现在要做的不是一个单纯生成文案的小工具，而是一个商家 AI 增长 SaaS。

核心产品应该这样定位：

```text
商家发需求
-> 系统接入需求
-> AI客服判断客户意向
-> 生成真实图片/真实视频/客服跟进方案
-> 商家在网页或抖音小程序订阅使用
-> 你收月费、部署费、定制费
```

## 两种东西不要混

### 1. Codex 本地插件

这是给你自己用的。

作用：

- 让 Codex 能直接引用你的商家增长工作流。
- 帮你改代码、检查 API、整理交付、部署排查。
- 不是卖给普通商家的产品。

当前插件位置：

```text
C:\Users\Administrator\plugins\merchant-growth-saas
```

### 2. 客户 SaaS 系统

这是卖给客户的。

客户应该通过：

- 网页 SaaS
- 抖音小程序
- 私有部署版本
- 代理商交付版本

来使用你的系统。

客户不应该安装 Codex，也不应该安装 Codex 插件。

## 你现在优先接入的功能

第一优先级：

```text
AI客服 + 线索沉淀 + 客户需求 API
```

第二优先级：

```text
真实图片生成
```

第三优先级：

```text
真实视频生成
```

第四优先级：

```text
抖音小程序订阅和支付
```

## 你卖给客户的话术

不要说：

```text
我做了一个 AI 生成文案工具
```

要说：

```text
老板发一句需求，系统自动生成图片、短视频、客服回复和线索跟进，适合抖音获客和商家成交。
```
