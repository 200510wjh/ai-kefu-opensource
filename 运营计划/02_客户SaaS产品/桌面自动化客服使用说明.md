# 桌面自动化客服使用说明

这个工具做的是“微信风格回复助手”，不是无人值守乱发消息。

## 它能做什么

1. 读取剪贴板里的聊天记录。
2. 调用 SaaS 后端接口分析客户最后说了什么。
3. 找出还没回复的客户消息。
4. 生成不傻的推荐回复。
5. 自动把推荐回复复制到剪贴板。
6. 可选：把回复粘贴到当前聊天输入框。

## 它现在不做什么

- 默认不会按 Enter 发送。
- 默认不会控制微信乱点。
- 不会绕过平台风控。
- 没有接企业微信/微信客服/抖音私信官方发送 API 前，不要做无人值守自动发送。

## 最安全用法

先复制聊天记录，例如：

```text
[我] 你好，你这个是做什么的
[对方] 我想做一个微信自动回复，可以识别当前聊天
[对方] 还能不要傻傻地回吗
```

然后在项目根目录运行：

```bash
npm run desktop:reply
```

运行后：

- 终端会显示待回复消息。
- 终端会显示推荐回复。
- 推荐回复会自动进入剪贴板。
- 你自己回到微信/客服窗口，按 `Ctrl+V` 粘贴，确认没问题后手动发送。

## 自动粘贴到当前聊天输入框

先点击微信或客服软件的输入框，让光标在输入框里。

然后运行：

```bash
npm run desktop:reply -- --paste
```

它会等待 3 秒，然后把推荐回复粘贴进去。

注意：这个命令只粘贴，不发送。

## 强制自动发送

不建议前期使用。

如果你确实要测试粘贴后自动按 Enter，需要显式确认：

```bash
npm run desktop:reply -- --paste --send --confirm-send 我确认发送
```

这会真实发送消息，请只在测试号、测试群或你明确允许的场景里用。

## 改用本地后端

默认接口是：

```text
https://wjhai.cn/merchant-admin/api
```

如果你本地开了后端，可以这样运行：

```bash
npm run desktop:reply -- --api-base http://127.0.0.1:8000/api
```

## 客户版应该怎么卖

前期不要卖“全自动发微信”，容易出事故。

更适合卖：

- AI 客服辅助回复
- 私信线索整理
- 客户意向判断
- 不傻回复推荐
- 人工确认后发送
- 企业微信/微信客服官方 API 接入定制

客户真正需要的是“少想怎么回、少漏线索、少傻回复”，不是完全不看就自动发。
