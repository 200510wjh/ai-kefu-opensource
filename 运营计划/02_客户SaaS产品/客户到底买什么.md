# 客户到底买什么

客户买的不是插件，也不是单纯文案。

客户买的是：

```text
商家 AI 增长 SaaS
```

## 客户看到的产品

客户进入网页或抖音小程序后，看到这些模块：

1. 创建需求
2. 上传商品图/门店图/口播视频
3. AI客服成交台
4. 生成图片
5. 生成短视频
6. 作品库
7. 线索和跟进
8. 套餐订阅

## 客户愿意付费的原因

商家不缺文案。

商家真正想要：

- 有人咨询时怎么回复
- 抖音怎么引流
- 商品图怎么做得能卖
- 短视频怎么快速做出来
- 客户线索怎么沉淀
- 能不能不用请运营也能跑

所以你的产品要卖：

```text
获客 + 转化 + 内容交付
```

## 建议套餐

### Starter

```text
99 元/月
适合个体商家
30 次生成
AI客服 + 图片生成 + 基础短视频方案
```

### Pro

```text
299 元/月
适合电商和门店
150 次生成
AI客服 + 主图 + 详情图 + 短视频 + 作品库
```

### Agency

```text
999 元/月起
适合代理商
团队账号 + 私有部署咨询 + 模板库 + API额度
```

## 最小可卖版本

先不要做完整剪映。

先做这个：

```text
客户发需求
-> AI客服判断意向
-> 生成主图
-> 生成短视频草稿
-> 保存作品
-> 引导订阅
```
