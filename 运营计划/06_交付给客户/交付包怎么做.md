# 交付包怎么做

客户不需要 Codex 插件。

客户需要一个能用的系统。

## 给客户的交付形式

### 1. SaaS 订阅

客户访问你的网址或小程序，注册后订阅。

适合：

- 个体商家
- 电商卖家
- 本地门店

### 2. 私有部署

你把系统部署到客户服务器。

适合：

- 代理商
- 大客户
- 有数据安全要求的团队

### 3. 代运营交付

客户不用系统，你帮他生成内容。

适合前期变现。

你可以卖：

```text
999 元：一套主图 + 详情图 + 3 条短视频
2999 元/月：每周内容 + AI客服跟进
```

## 打包给客户的文件

客户交付包可以包含：

```text
客户操作说明.pdf
账号开通信息
套餐说明
素材上传规范
生成结果示例
售后联系方式
```

如果是私有部署，再加：

```text
部署文档
环境变量模板
服务器要求
API Key 配置说明
运维说明
```

## 你自己内部用的文件

内部才需要：

```text
Codex本地插件
项目源码
部署脚本
API调试文档
运营计划
```

不要把内部 API Key、服务器密码、Codex 插件直接发给普通客户。
